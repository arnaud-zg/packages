## Package findability (SEO)

Nobody promotes these packages; npm search and web search are how users find them. When you add a
package or change a `package.json` `description`/`keywords` or a README opening, follow
[docs/contributing/reference.md § Findability rules](docs/contributing/reference.md#findability-rules)
and the steps in
[docs/contributing/how-to.md § Keep a package findable](docs/contributing/how-to.md#keep-a-package-findable).
Metadata only reaches npm on the next release, so such a change needs a patch changeset.
